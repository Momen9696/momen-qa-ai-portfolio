# Mo'men Ali — QA automation and AI testing portfolio

Public portfolio site for six demonstration repositories. The projects are working local systems with tests and reports. They were not delivered to a paying client.

## Stack

React, TypeScript, and Vite. Routing is React Router. Tests are Vitest and Testing Library.

## Run

```bash
npm install
npm test
npm run lint
npm run build
npm run dev
```

Open http://127.0.0.1:5173.

Production on GitHub Pages uses the base path `/momen-qa-ai-portfolio/`. Local commands leave the base as `/`. The Pages workflow sets `GITHUB_PAGES=true`.

## What is verified

Project descriptions in `src/content.ts` come from reading the six repositories and re-running their test commands on 24 November 2026. Screenshots in `public/evidence/` are captures of those applications or of reports the tools wrote. Files in `public/brand/` are cover and service illustrations, not product screenshots. Diagrams in `public/diagrams/` follow the dependency direction described in each repository.

Contact email and the Upwork profile URL are placeholders.
